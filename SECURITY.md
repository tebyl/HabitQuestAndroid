# Política de seguridad

## Versiones compatibles

HabitQuest se encuentra en desarrollo activo. Las correcciones de seguridad se
aplican a la versión más reciente y a la rama `master`.

## Informar una vulnerabilidad

No publiques vulnerabilidades en un issue. Usa **Report a vulnerability** en la
pestaña **Security** del repositorio para enviar un informe privado mediante
GitHub Security Advisories.

Incluye, cuando sea posible:

- una descripción del problema y su impacto;
- pasos mínimos para reproducirlo;
- la versión de Android y el dispositivo afectados;
- una prueba de concepto sin información personal;
- una propuesta de corrección, si está disponible.

El informe se revisará antes de divulgar detalles públicamente. No accedas,
modifiques ni elimines datos de terceros durante la investigación.

## Secretos y datos locales

HabitQuest almacena su información localmente. Nunca añadas al repositorio
claves de firma, archivos `keystore`, contraseñas, tokens ni copias de bases de
datos que puedan contener información personal.
